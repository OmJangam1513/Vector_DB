# Basic Vector Database using ChromaDB

A beginner-friendly Python project demonstrating the fundamentals of vector databases using ChromaDB. It covers collection creation, document storage, automatic embedding generation, document IDs, and retrieving embeddings.

## Features

- Create and manage collections
- Add documents with unique IDs
- Generate embeddings automatically using the default embedding function
- Retrieve documents, metadata, and embeddings
- Inspect embedding dimensions and vector values

## Technologies Used

- Python
- ChromaDB
- uv for dependency management

## Installation

```bash
uv init
uv add chromadb notebook ipykernel
```

## Usage

Run your Python script or Jupyter Notebook to create a collection, insert documents, and retrieve their embeddings.

## Learning Objectives

- Understand the basics of vector databases
- Learn how text is converted into numerical embeddings
- Explore document storage and retrieval
- Understand how ChromaDB manages collections and vectors
